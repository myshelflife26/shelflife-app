📦 YoJoe → ShelfLife Scraper

This bookmarklet lets you scrape G.I. Joe figures directly from YoJoe.com and export them as CSV for ShelfLife.

⚠️ CORS Limitation: Browsers block direct scraping from other websites. This bookmarklet runs on YoJoe.com itself, bypassing the restriction.

📚 How to Install

Step 1: Drag this button to your bookmarks bar:

🚀 Scrape YoJoe
Step 2: Visit a YoJoe year page
Example: https://www.yojoe.com/action/82/
Step 3: Click the "Scrape YoJoe" bookmark you just added
Step 4: A CSV file will download automatically
Step 5: Import the CSV into ShelfLife:
  • Settings → Scrape Figures
  • Select "CSV/TSV Import"
  • Open the downloaded CSV file and copy all contents
  • Paste into ShelfLife scraper
  • Click "Import All"

🎯 What It Does

The bookmarklet:

  • ✅ Extracts figure names from the page
  • ✅ Detects year from URL
  • ✅ Captures version numbers (V1, V2, etc.)
  • ✅ Grabs image URLs
  • ✅ Removes duplicates
  • ✅ Exports as CSV

📋 Example Workflow

Import All Vintage Figures (1982-1994):
  1. Visit https://www.yojoe.com/action/82/
  2. Click bookmarklet → downloads "yojoe-figures-1982.csv"
  3. Visit https://www.yojoe.com/action/83/
  4. Click bookmarklet → downloads "yojoe-figures-1983.csv"
  5. Repeat for each year...
  6. Import all CSV files into ShelfLife

🔧 Troubleshooting

"No figures found"

  • Make sure you're on a year listing page (e.g., /action/82/)
  • Don't use on individual figure pages

Bookmarklet doesn't work

  • Try dragging it again to bookmarks bar
  • Make sure JavaScript is enabled
  • Try in a different browser

📝 Manual Code (Advanced)

If dragging doesn't work, create a bookmark manually:

  1. Create a new bookmark
  2. Name it "Scrape YoJoe"
  3. Paste this code in the URL field:
javascript:(function(){const figures=[];const links=document.querySelectorAll('a[href*=".shtml"]');const yearMatch=window.location.href.match(/\/action\/(\d+)\//);let year=undefined;if(yearMatch){const shortYear=parseInt(yearMatch[1]);year=shortYear<50?2000+shortYear:1900+shortYear}const seenNames=new Set();for(const link of Array.from(links)){const title=link.title||'';const img=link.querySelector('img');const alt=img?.alt||'';let figureName=title||alt;if(!figureName)continue;const cleanName=figureName.replace(/\s*\(v\d+\)\s*/gi,'').trim();if(seenNames.has(cleanName.toLowerCase()))continue;seenNames.add(cleanName.toLowerCase());let version='';const versionMatch=figureName.match(/\(v(\d+)\)/i);if(versionMatch)version=`V${versionMatch[1]}`;let imageUrl='';if(img?.src){imageUrl=img.src.startsWith('http')?img.src:`https://www.yojoe.com${img.src}`}figures.push({name:cleanName,manufacturer:'Hasbro',productLine:'G.I. Joe',subProductLine:year?`${year}`:'',year:year||'',version:version,category:'Action Figure',size:'3.75"',packaging:'Individual',imageUrl:imageUrl})}if(figures.length===0){alert('No figures found on this page. Make sure you\'re on a YoJoe year listing page (e.g., /action/82/)');return}const csv=[['name','manufacturer','product line','sub product line','year','version','category','size','packaging','image'].join(','),...figures.map(f=>[f.name,f.manufacturer,f.productLine,f.subProductLine,f.year,f.version,f.category,f.size,f.packaging,f.imageUrl].map(v=>`"${v}"`).join(','))].join('\n');const blob=new Blob([csv],{type:'text/csv'});const url=URL.createObjectURL(blob);const a=document.createElement('a');a.href=url;a.download=`yojoe-figures-${year||'export'}.csv`;a.click();URL.revokeObjectURL(url);alert(`Exported ${figures.length} figures!\nImport the CSV file into ShelfLife.`)})()

🎉 Done!

You now have a working YoJoe scraper that bypasses CORS restrictions. Happy collecting!
